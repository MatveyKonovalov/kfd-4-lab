## 2. Реализация и модули

Анализатор обрабатывает файлы с расширениями `kt`, `kts`, `md`, считает количество файлов и строк по расширениям, а также выводит до трёх самых длинных файлов. При равном количестве строк используется сортировка относительных путей. Пустой файл учитывается как 0 строк, последняя строка без перевода строки также учитывается.

Проект разделён на два модуля:

- `core` — обход каталогов, подсчёт строк, модели результатов, сортировка и тесты;
- `cli` — аргументы командной строки, вывод отчётов и коды завершения.

Модуль `cli` зависит от `core` через `implementation(project(":core"))`, поскольку использует его API. Обратная зависимость не нужна: логика анализа не зависит от консольного интерфейса.

## 3. Тесты и запуск

В `core/src/test/kotlin/fileworker/MainTest.kt` находятся три теста: проверка обоих отчётов, пустого каталога и некорректного пути. Сохранённый XML-отчёт Gradle содержит **3 теста, 0 ошибок и 0 падений**.

Запуск:

```bash
bash ./gradlew run --args="core/src/test/kotlin/testdirectories/test1" --no-configuration-cache --console=plain
```

Для тестового каталога ожидается:

```text
kt: 2 files, 4 lines
md: 1 files, 0 lines
src/A.kt (2)
src/B.kt (2)
README.md (0)
```

## 4. Сборка Gradle

Выполнена команда:

```bash
bash ./gradlew build --no-configuration-cache --no-build-cache --console=plain
```

Результат:

```text
BUILD SUCCESSFUL in 1s
10 actionable tasks: 10 up-to-date
```

` :core:compileKotlin`, `:core:test`, `:cli:compileKotlin`, `:core:build` и `:cli:build` имеют статус `UP-TO-DATE`. Это означает, что Gradle не обнаружил изменений входных данных, требующих повторного выполнения задач.

Предоставленный лог подтверждает успешную сборку, но не подтверждает эксперимент с правкой `core`: в нём нет сведений о внесённом изменении и повторной сборке после него. Поэтому фактические статусы задач после такой правки не указываются.

## 5. Вывод

После разделения CLI использует библиотечный модуль `core`, а расчёты и тесты остаются независимыми от запуска приложения. Тесты подтверждают работу отчётов на тестовом каталоге, пустом каталоге и при некорректном пути. Предоставленный запуск Gradle завершился успешно.
